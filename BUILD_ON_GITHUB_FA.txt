ساخت FrameLock بدون نصب Visual Studio یا CMake روی کامپیوتر شما

این روش از کامپیوترهای ویندوزی GitHub برای کامپایل استفاده می‌کند. روی سیستم خودتان فقط مرورگر لازم دارید؛ یک حساب GitHub نیز لازم است.

۱) فایل ZIP را Extract کنید.
۲) وارد https://github.com شوید و وارد حساب شوید.
۳) از علامت + گزینه New repository را انتخاب کنید. یک نام مثل FrameLock بگذارید و Create repository را بزنید. مخزن می‌تواند Private باشد.
۴) در مخزن، Add file > Upload files را بزنید. وارد پوشه FrameLock که از ZIP استخراج شده‌اید شوید و **محتویات داخل آن** را انتخاب و در ریشه مخزن آپلود کنید (خود پوشه FrameLock را به‌صورت یک پوشهٔ تو در تو آپلود نکنید). ساختار `src` و `.github/workflows` باید حفظ شود. فایل `.github/workflows/windows-build.yml` ضروری است.
۵) بعد از Commit کردن فایل‌ها، وارد تب Actions شوید. اگر GitHub پرسید Actions را فعال کنید، آن را فعال کنید.
۶) از فهرست سمت چپ «Build FrameLock for Windows» را انتخاب کنید، دکمه Run workflow و سپس Run workflow را بزنید.
۷) وقتی اجرای کار با علامت سبز تمام شد، همان صفحه اجرای workflow را باز کنید. پایین صفحه در بخش Artifacts فایل FrameLock-Windows را دانلود کنید.
۸) ZIP خروجی را Extract کنید. برای بازی ۶۴ بیتی، FrameLock64.exe را کنار FrameLockHook64.dll اجرا کنید. برای بازی ۳۲ بیتی، FrameLock32.exe را کنار FrameLockHook32.dll اجرا کنید.

نکات:
- این بسته هنوز خروجی کامپایل‌شده نیست؛ workflow کامپایل را روی سرور GitHub انجام می‌دهد.
- اگر Build قرمز/Fail شد، وارد همان اجرا شوید و متن خطای اولین مرحله قرمز را بفرستید.
- این پروژه هنوز روی بازی‌های مختلف آزمایش نشده و سازگاری عمومی یا عملکرد قطعی تضمین نمی‌شود. Vulkan هم در نسخه سورس فعلی پیاده‌سازی نشده است.
- در بازی‌های آنلاین یا دارای anti-cheat از تزریق DLL استفاده نکنید.
